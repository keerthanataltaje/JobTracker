# Job Tracker🎯

A decoupled full-stack job application tracker and networking CRM. It manages application lifecycles, tracks professional contacts (recruiters and referrers), and integrates AI pipelines for automated cover letter generation and follow-up nudges.

---

## 🛠️ Tech Stack

* **Backend:** Java 21, Spring Boot 3, Spring Data JPA, Spring Security (JWT), PostgreSQL
* **Frontend:** Angular 17+, TypeScript, RxJS
* **AI & Integrations:** Google Gemini
* **Build & Tools:** Maven
---

## 🚀 Key Features

* **Pipeline Management:** Track applications across lifecycle stages (`APPLIED`, `INTERVIEWING`, `OFFER`, `REJECTED`) with an interactive Kanban board.
* **Network CRM:** Centralized directory linking recruiters and referrers directly to active job opportunities.
* **AI Automation:** Dynamic cover letter generation, ATS resume gap analysis, and automated inactivity nudges.
